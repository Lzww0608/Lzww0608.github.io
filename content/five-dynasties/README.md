# 五代史料本地文库

本目录保存可直接阅读的原文、目录和来源响应，供本机 PostgreSQL 与静态网站共同使用。当前收录 **9 部史料、151 个篇章（147 卷及 4 篇卷外提要／序文）、7,044 个文字块、980,523 个 Unicode 字符**（含标点、原页夹注和序文）。本目录仅保存繁体底本；已发布译文单独保存在 `content/published-translations/`。

这里的“完整”指表中选定卷的来源正文完整收录，不表示旧史 150 卷或新史 74 卷全书已经收录。《新五代史》卷 7 合记后唐愍帝与废帝、卷 10 合记后汉高祖与隐帝、卷 12 合记后周世宗与恭帝，均整卷保留。朱友珪虽被追废，曾实际登位；两书将其事迹分别收入宗室传和家人传，不为他虚构独立本纪。《资治通鉴》以编年史分类，人物关联按在位叙事及交接卷定位，不是所有提及该人物的穷尽索引。《五代史阙文》是补充史料笔记，传闻应与正史、编年史相互参证。《五代史补》《北梦琐言》同属笔记史料；《五代春秋》是编年史，《五代会要》是典章制度资料，《资治通鉴考异》记载史料异同与取舍理由。未收录《北梦琐言》全部二十卷，也未收录《资治通鉴考异》全部三十卷。

补充书的提要与序文以 `volume: 0` 单列，使用明确篇名；目录位置与真实卷号分开保存。人物关联用于整篇参读，不等于该篇全部内容属于此人的传记。补充史料依据明确姓名或可辨认帝号关联，避免将孤立的“太祖”“高祖”误认。

共享 `emperors.json` 收录后梁、后唐、后晋、后汉、后周实际在位的十四位皇帝，包括朱友珪；未实际即位的刘赟不计入。资料保存稳定人物 ID、姓名与别名、在位年份、简介、来源以及 `readingStarts` 主阅读入口；在位年按对应的西历年份标示，年号末年可能跨入翌年。`catalog.json` 的 `subjects` 关联本纪／专传的记载对象、编年史的在位叙事与交接卷，以及补充史料中可辨认的姓名或帝号。前端先验证主入口归书及人物关联，再回退到相关编号篇章，不将次要提及当作个人主传。

本轮新增旧史 33 篇 583 段、新史 6 篇 169 段，共 39 篇 752 段原文与对应译文，已完成校核、导入、发布及公开副本导出。当前 151 篇、7,044 段归档均已配有已发布译文；此前 112 篇的原始响应、正文、段落 ID、修订号、校验值和 6,292 条既有译文保持不变。静态网站副本更新另须完成前端构建、部署与在线验证。

每卷 `catalog.json` 的 `provenance` 保存固定修订链接、修订号、贡献者历史链接、采集时间、授权链接，以及来源响应与正文文件的 SHA-256。阅读页的“出处与版本信息”提供同样的署名与版本入口。完整贡献者名单可沿各卷 `contributorsUrl` 查询。

## 文件与维护

- `catalog.json`：公开目录、人物关联、来源与校验值。
- `emperors.json`：十四位在位皇帝的共享人物资料、来源依据与主阅读入口；不改写章节底本。
- `chapters/*.json`：按卷保存的完整纯文字原文，段落 ID 固定，如 `old-v110-p1`。
- `sources/*.json`：采集时间和维基文库 `action=parse` 原始响应，保留原页 HTML 与修订号；不在页面中执行 HTML。

项目根目录执行：

```sh
python3 tests/archive_sources_test.py
node frontend/scripts/prepare-content.mjs
```

前端启动和构建会自动复制已校验的公开目录与正文到 `frontend/public/history/`，正文逐卷加载。原始 HTML 不随静态站发布。API 暂时离线时仍可读取静态站的完整原文；尚未实现首次访问也完全断网的浏览器缓存。

本机数据库导入前先备份并验证，再执行 `npm run content:import --prefix backend`。导入仅补缺失记录，保留已有原文修订、译文与发布状态。旧的 2 个节选章节及其段落 ID 作为兼容记录保留，不计入上面的 151 个篇章。

`python3 scripts/archive-sources.py` 先校验并沿用已有归档；新增篇章从保存的原始响应生成，缺少响应时才下载。未来采集新版本应创建新的归档/版本并显式迁移段落，不能删除来源响应后原地重抓并改变已有段落 ID。
