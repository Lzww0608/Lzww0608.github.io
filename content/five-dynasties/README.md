古籍原作属于公版。维基文库整理、标点、注释及页面文本按其来源页面所示的 [Creative Commons 署名—相同方式共享 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 共享。本目录的归档整理文本、格式转换结果及随附阅读提示也按该协议共享。此授权限定于史料归档，不自动改变网站应用代码、图片或其他第三方素材的授权。没有宣称维基文库或维基媒体基金会认可本项目。

每卷 `catalog.json` 的 `provenance` 保存固定修订链接、修订号、贡献者历史链接、采集时间、授权链接，以及来源响应与正文文件的 SHA-256。阅读页的“出处与版本信息”提供同样的署名与版本入口。完整贡献者名单可沿各卷 `contributorsUrl` 查询。

本次对来源的改动仅包括：去除站点导航、许可模板与样式；将历史正文、标题、序文、夹注和脚注提取为纯文字；按 HTML 段落与空行划分文字块；统一非正文的多余空白。未自动简繁转换、改写史事或生成翻译。标题和阅读提示由本站整理，并与正文分别保存。原始 HTML 响应可用于复核格式转换。

## 文件与维护

- `catalog.json`：公开目录、人物关联、来源与校验值。
- `chapters/*.json`：按卷保存的完整纯文字原文，段落 ID 固定，如 `old-v110-p1`。
- `sources/*.json`：采集时间和维基文库 `action=parse` 原始响应，保留原页 HTML 与修订号；不在页面中执行 HTML。

项目根目录执行：

```sh
python3 tests/archive_sources_test.py
node frontend/scripts/prepare-content.mjs
```

前端启动和构建会自动复制已校验的公开目录与正文到 `frontend/public/history/`，正文逐卷加载。原始 HTML 不随静态站发布。API 暂时离线时仍可读取静态站的完整原文；尚未实现首次访问也完全断网的浏览器缓存。

本机数据库导入前先备份并验证，再执行 `npm run content:import --prefix backend`。导入仅补缺失记录，保留已有原文修订、译文与发布状态。旧的 2 个节选章节及其段落 ID 作为兼容记录保留，不计入上面的 64 卷。

`python3 scripts/archive-sources.py` 可从已保存的原始响应重新生成同一归档；已有来源响应不会再次下载。未来采集新版本应创建新的归档/版本并显式迁移段落，不能删除来源响应后原地重抓并改变已有段落 ID。
