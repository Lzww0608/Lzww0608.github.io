# 事件史料对读

首个专题为柏乡之战：按求援背景、战前部署、决战、战后攻守四个阶段，选取当前归档五部作品的52个完整相关段落，并列9条有原文依据的记载差异。所选作品为《旧五代史》《新五代史》《资治通鉴》《五代会要》《五代春秋》，不宣称九部均有完整战程或覆盖未归档全书。

胡柳陂之战使用 `huliu.json`：六书37个完整相关段落、四阶段及12条记载说明，新增《资治通鉴考异》仅用于袁建丰相州任职年代考证。战前相持始于918年，决战在原书记年十二月已跨西历919年；不同宿营与战日、周德威军阵方位、李嗣源北渡与石敬瑭从其复击的两组叙法、俘斩和死亡等统计口径分别保留。完整原段的后来德胜水战、同州作战及追赠不冒充胡柳当日，未选入的作品不据此断言全书无记载。

晋阳之战与后晋建立使用 `jinyang.json`：三书71个完整原段，分调镇起兵与求援、晋阳解围与晋安反围、册立割地与晋安结局、南下入洛与后唐覆亡四阶段。跨阶段长段可在不同阶段完整出现，引用仍只登记一次；册文六段连续选入，夹注、符瑞与史评明确注明层次。交战日与奏报日、册立与晋安杀降的先后、许地与割约、劝杀与实际杀害分开阅读；原书年号末期已经跨入937年。当前选源不等于三书全本，也不将同源夹注变成第四部作品。

JSON只保存稳定事件与阶段ID、人物关联、原段引用、修订／SHA-256及差异的连续引文，不复制或改写原文、译文和校订历史。保留完整相关段落；本传和编年长段内的其他役次不等于柏乡当日。不同兵数、战日与日食、俘虏统计分别展示，不把未提及当成否认，不合成唯一总数。王建及与李建及复用同一人物身份，回称庄宗不等于当时已称帝。

`content/event-comparisons.mjs`与前端共享schema检查全部引用、归书、当前原文及配套公开全文、连续引文和阶段归属，prebuild在生成副本前执行。页面复用已有章节只读API；成功响应缺段、原文变化、译文缺失或无效内容均暂停相关来源及依赖的差异结论，只有网络不可达才读取相应随站章节。最新匹配的已发布全文优先，差异说明针对绑定底本的事实而非旧译文措辞。

从人物页和相关人物条目进入`#event-comparison/baixiang`、`#event-comparison/huliu`或`#event-comparison/jinyang`。阶段地址可刷新，并能从原篇具体段落返回；书籍选择、阶段与阅读位置沿共用浏览器阅读记录保存，译文默认收起，可独立或一并展开。繁简、三配色、字号、句译和可收起目录沿用共用阅读规则。每个专题与人物年表的关联保存于独立共用注册表，不混用事件或阶段。新对读专题需真实语义对读、独立复核，完成构建、部署、线上核对和指定私有仓库备份。
