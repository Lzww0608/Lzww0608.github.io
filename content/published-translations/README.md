# 已发布白话译文

本目录仅保存用户授权公开、已写入数据库的白话译文副本。按用户最新要求，阅读页统一显示“白话译文”，不展示 AI／待修订提示；来源和审核元数据按实际保留，公开不代表已经人工审核。译文由 Codex 根据本站繁体底本直接翻译；底本及维基文库贡献者的出处、版本和署名沿用原文档的来源信息。本目录公开译文与整理文本按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 分享。

当前共收录 7,044 条已发布译文：`chunqiu.json` 为《五代春秋》提要、上下卷的 76 条（含标题）；`new.json` 为《新五代史》卷 1—12 本纪及卷 13 梁家人传的 333 条；`quewen.json` 为《五代史阙文》提要、序文和全卷的 44 条；`shibu.json` 为《五代史补》五卷与归档提要、作者序、逸文的 214 条；`beimeng.json` 为《北梦琐言》四库本卷 17—20 及提要、自序的 147 条；`kaoyi.json` 为《资治通鉴考异》四库本卷 28—30 的 178 条；`old.json` 为《旧五代史》59 卷本纪及卷 12 梁宗室传的 1,108 条，均保留底本夹注、辑佚说明与校勘注；`huiyao.json` 为《五代会要》提要和全部 30 卷、31 篇的 1,922 条，完整保留制度条文的主体、数额、资格和例外，底本疑点另列校核提示；`tongjian.json` 为《资治通鉴》当前归档卷 266—294、29 卷的 3,022 条，覆盖 907—959 年，保留编年叙事、纪年、对话、夹注和司马光评议。九部史料当前归档的 151 篇均已配有已发布译文；《资治通鉴》范围不是全部 294 卷。这不是《新五代史》《旧五代史》《北梦琐言》或《资治通鉴考异》全本翻译。各条以稳定段落 ID、原文修订与 SHA-256 绑定底本，保留译文版本、实际来源、审核状态和校核提示。

本轮人物资料已扩展至十四位实际在位皇帝，包括朱友珪，不含未实际即位的刘赟。原文目录现有 151 篇 7,044 段：《旧五代史》59 卷本纪及卷 12 梁宗室传共 60 篇、1,108 段；《新五代史》卷 1—12 本纪及卷 13 梁家人传共 13 篇、333 段。本轮新增旧史 33 篇 583 段、新史 6 篇 169 段的 752 段译文已完成校核、导入、发布及导出；当前公开快照共 7,044 条，此前 112 篇的 6,292 条原文与译文保持不变。这是归档范围的翻译，不是新旧五代史全本；数据库发布与副本导出不能代替静态网站的构建、部署及在线验证。共享人物主入口与整篇关联分别维护在原文目录的 `emperors.json` 和 `catalog.json`，不改变底本或已有译文绑定。

构建时验证并叠加到网站生成的篇章文件，原文归档 `content/five-dynasties/` 不变。只导出数据库中当前已发布、与底本匹配的译文，不复制私人草稿、密码、原始批次或数据库备份。

线上阅读优先使用本机 API 的最新版本。API 离线时读取最近部署副本；在线修订存入数据库后，需要再次导出、构建并发布，才能更新离线副本。

在线校订仅允许通过所有者密码验证后追加新的已发布译文版本，保留原文、旧译文及 AI 来源链；`owner-edited` 只表示所有者修改，不代表专业审核。公开阅读账户保持只读，独立校订账户只执行专用数据库函数。密码只保留当前页面内存，不写入浏览器持久存储或 Cookie。所有者本机密钥位于 Git 忽略的 `backend/.local/editor-key.txt`；本目录不能包含该文件内容、私有配置、原始批次或备份。
