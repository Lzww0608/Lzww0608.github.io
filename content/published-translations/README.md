# 已发布白话译文

本目录仅保存用户授权公开、已写入数据库的白话译文副本。AI 初译明确标为“待修订”，公开不代表已经人工审核。译文由 Codex 根据本站繁体底本直接试译；底本及维基文库贡献者的出处、版本和署名沿用原文档的来源信息。本目录公开译文与整理文本按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 分享。

`chunqiu.json` 收录《五代春秋》提要、上下卷的 76 条初译（含标题）。《新五代史》已选七卷的初译完成后导出为 `new.json`。各条以稳定段落 ID、原文修订与 SHA-256 绑定底本，保留译文版本、AI／人工来源和校核提示。

构建时验证并叠加到网站生成的篇章文件，原文归档 `content/five-dynasties/` 不变。只导出数据库中当前已发布、与底本匹配的译文，不复制私人草稿、密码、原始批次或数据库备份。

线上阅读优先使用本机 API 的最新版本。API 离线时读取最近部署副本；在线修订存入数据库后，需要再次导出、构建并发布，才能更新离线副本。

```sh
npm run translations:export --prefix backend -- chunqiu
```
