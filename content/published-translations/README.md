# 已发布白话译文

本目录仅保存用户授权公开、已写入数据库的白话译文副本。AI 初译明确标为“待修订”，公开不代表已经人工审核。译文由 Codex 根据本站繁体底本直接试译；底本及维基文库贡献者的出处、版本和署名沿用原文档的来源信息。本目录公开译文与整理文本按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 分享。

当前共收录 240 条已发布 AI 初译，全部仍待人工校核：`chunqiu.json` 为《五代春秋》提要、上下卷的 76 条（含标题）；`new.json` 为《新五代史》当前归档的卷 1、2、4、5、8、10、11 共 164 条，保留所选卷中的夹注与校勘注。这不是《新五代史》全本翻译。各条以稳定段落 ID、原文修订与 SHA-256 绑定底本，保留译文版本、AI／人工来源和校核提示。

构建时验证并叠加到网站生成的篇章文件，原文归档 `content/five-dynasties/` 不变。只导出数据库中当前已发布、与底本匹配的译文，不复制私人草稿、密码、原始批次或数据库备份。

线上阅读优先使用本机 API 的最新版本。API 离线时读取最近部署副本；在线修订存入数据库后，需要再次导出、构建并发布，才能更新离线副本。

在线校订仅允许通过所有者密码验证后追加新的已发布译文版本，保留原文、旧译文及 AI 来源链；`owner-edited` 只表示所有者修改，不代表专业审核。公开阅读账户保持只读，独立校订账户只执行专用数据库函数。密码只保留当前页面内存，不写入浏览器持久存储或 Cookie。所有者本机密钥位于 Git 忽略的 `backend/.local/editor-key.txt`；本目录不能包含该文件内容、私有配置、原始批次或备份。

```sh
npm run translations:export --prefix backend -- chunqiu
npm run translations:export --prefix backend -- new
```
