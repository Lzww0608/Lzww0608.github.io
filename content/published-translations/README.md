# 已发布白话译文

本目录仅保存用户授权公开、已写入数据库的白话译文副本。按用户最新要求，阅读页统一显示“白话译文”，不展示 AI／待修订提示；来源和审核元数据按实际保留，公开不代表已经人工审核。译文由 Codex 根据本站繁体底本直接翻译；底本及维基文库贡献者的出处、版本和署名沿用原文档的来源信息。本目录公开译文与整理文本按 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 分享。

当前共收录 7,811 条已发布译文，覆盖九部史料归档的 175 篇：《旧五代史》所选 74 篇、1,426 条；《新五代史》所选 23 篇、782 条；《资治通鉴》卷 266—294 的 29 篇、3,022 条；《五代会要》提要与全部 30 卷的 31 篇、1,922 条；《五代春秋》76 条；《五代史阙文》44 条；《五代史补》214 条；《北梦琐言》147 条；《资治通鉴考异》178 条。含标题、夹注、辑佚与校勘注；这不是新旧《五代史》、《北梦琐言》、《资治通鉴》或《资治通鉴考异》全本翻译。各条以稳定段落 ID、原文修订与 SHA-256 绑定底本，保留译文版本、实际来源、审核状态和校核提示。

人物资料覆盖十四位实际在位皇帝、“十三太保相关人物”专题新增十一人及“朱温帐下将领”专题新增五十三人，共 78 人；太保成员复用李嗣源、李存勖两个皇帝 ID，区别亲子、养子和部将，不作为史书固定十三人或共同排行。共享资料见原文目录的 `emperors.json`、`taibao.json` 和 `zhu-wen-generals.json`，整篇参读关联在 `catalog.json`，个人记载由共享片段索引派生，不改变底本或已有译文绑定。

本轮补充朱温将领相关旧史卷 13、16、19—23、59、63、64 的 225 段和新史卷 21—23、32、43—46 的 357 段，共十八卷、582 段。完整译文已逐段／逐句核对，通过隔离恢复库中同一批次的原子导入测试，并在正式库完成已授权的导入、发布及副本导出。此前 157 篇、7,229 段的原文和已发布译文逐行 SHA-256 保持不变。实际审核状态仍为 `humanReviewed: false`，工具校核不冒充人工专业审核。新增句号范围以实际发布译文 ID、版本和双 SHA-256 绑定；不能安全独立释义的碎片保留提示和可展开的完整译文。静态网站更新仍须完成构建、部署和在线验证，以对应 GitHub Actions 的精确提交为准。

构建时验证并叠加到网站生成的篇章文件，原文归档 `content/five-dynasties/` 不变。只导出数据库中当前已发布、与底本匹配的译文，不复制私人草稿、密码、原始批次或数据库备份。

线上阅读优先使用本机 API 的最新版本。API 离线时读取最近部署副本；在线修订存入数据库后，需要再次导出、构建并发布，才能更新离线副本。

在线校订仅允许通过所有者密码验证后追加新的已发布译文版本，保留原文、旧译文及 AI 来源链；`owner-edited` 只表示所有者修改，不代表专业审核。公开阅读账户保持只读，独立校订账户只执行专用数据库函数。密码只保留当前页面内存，不写入浏览器持久存储或 Cookie。所有者本机密钥位于 Git 忽略的 `backend/.local/editor-key.txt`；本目录不能包含该文件内容、私有配置、原始批次或备份。
