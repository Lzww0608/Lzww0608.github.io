# 文白句组显示索引

此目录给共用阅读组件提供点击原文后的译文范围，不保存第二份原文或译文，也不写数据库。`chapters/<chapterId>.json` 覆盖当前公开归档的 157 篇、7,229 段，分别绑定稳定段落 ID、原文修订及 SHA-256、当前已发布译文 ID、版本及全文 SHA-256。范围是 Unicode 码点位置，不是 UTF-16 下标；每段所有组按原译文顺序连续、无重叠、完整覆盖两边已有文字。

重新生成使用 `node scripts/index-sentence-alignments.mjs`；核对保存结果使用 `node scripts/index-sentence-alignments.mjs --check`。生成器读取既有规范归档及公开译文副本，OpenCC 只用于离线寻找共同短语，任何原文、译文、段落 ID 与数据库记录均不改变。前端构建将逐章索引复制到站内；API 当前译文优先。运行时原文或译文任一 ID、版本、校验值不符，旧范围不适用，显示当前整段译文，不能临时按句数套配。

## 分句与边界

共用 `frontend/src/sentence-alignment.ts` 按外层 `。！？` 识别句子，闭引号与空白保留在前面的范围，拼接必定逐字还原原文。`〈〉`、`【】`、`〔〕`、`（）`、`()` 的嵌套校勘注保持完整；注释里的句号不会把官职、叙事或主句拦腰截断。独立注释整体是一个注释单位，无外层句末的单位与相邻组保守合并，或作为整段回退，不因夹注内有句号就称为独立主句。

自动分界仅采用原译文两边独立出现一次的 4—6 字共同短语。源边界紧邻两侧都至少有 5 字匹配证据，所有唯一锚的前后顺序必须一致，且两侧锚之间恰有一个译文分界。左右尾部与头部也要有正向边界证据：同一共同强锚位于原译左单位最后约 12 字、距两边末尾不超过 3 字；另一共同强锚在原译右单位开头 3 字内出现。位置按规范化后的汉字、数字计算，标点和闭引号不充当尾部证据。独有 2—3 字短语若跨越候选分界，只作为否决该分界的矛盾证据，绝不用来建立新边界；这一保护扫描所有段落，不按篇幅限制。证据冲突、缺少锚或多种分界可能时，保留较大句组；译文尾部无共同锚时整段回退，以免把统一解释挂到最后一句。存在“意思是”“意为”“诗意”“换成白话”等复述再解释的提示时不自动细分。这是保守的结构对齐方法和抽检结果，不是每句已获人工语义审核或百分之百精确对照的声明。不能以原译文句数相等、字符长度比例或源译字符位置相同来建立关系。

`kind: sentence` 表示一个有外层句末的原句，允许对应多个已有译句；`group` 表示多个原文句子/注释单位对应已有译文句组；`paragraph` 明确表示本段译文。底本没有句读、译文合并多句而边界不明，以及无法可靠细分的情况都保留整段。用户界面应分别显示“本句译文”“对应句组译文”或“本段译文”，不得把整段回退或自动合并冒称精确单句。

## 已核对例外与维护

`overrides.json` 记录个别已逐句核对的拆合范围和原因，仍绑定原文 SHA-256、译文 ID、版本与 SHA-256；校订后旧例外失效并停止生成，需重新核对。当前包含李存信相关的 `new-v06-p2`、`new-v36-p17`，李存孝 `new-v36-p19`，法律与幕僚处境及官职纪日叙事 `old-v101-p7`，一原句分两译句 `new-v03-p30`，庄宗博戏与中箭之说 `quewen-v001-p17`，闽国大赦及改元的两原句合译 `tongjian-v279-p82`，安金全籍贯及生平 `new-v25-p45`，以及整诗复述后统一释义而明确整段回退的 `shibu-v001-p42`。`old-v115-p12`、`tongjian-v269-p70`、`old-v101-p1`、`huiyao-v022-p14` 的现有译文跨句挪动短条款，核对后也明确整段回退。此校核保留既有译文的实际审核状态，不将工具校核冒充人工审核。

新增史料或导出新的已发布译文后，重跑生成、核对不可靠边界和跨句组解释，并运行 `frontend/tests/sentence-alignment.test.mjs` 及项目完整前端检查。维护者可增加带原因的句组例外，或 `mode: paragraph` 保守回退；不要为了减少回退数量而弱化绑定、强行拆句或修改既有译文。公开只保证当前归档已有版本，未归档全书不在范围内。

当前生成结果为 9,238 个连续范围，其中 2,739 个单原句范围、1,836 个句组范围、4,663 个整段回退；后续校核和新内容会改变此统计。
