# 当前归档的人物记载索引

本索引检索当前人物目录与完整归档。它不是新底本，也不改写任何原文、译文、段落 ID 或修订记录。`index.json` 只保存段落引用、原文 SHA-256、修订号、Unicode code point 范围和人物关联；同一原文段落由所有关联人物共享一个片段。当前最小片段是完整段落，范围为 `0` 到原文的 code point 长度。

生成和检查：

```sh
node scripts/index-person-passages.mjs
node scripts/index-person-passages.mjs --check
node --test tests/person-passages.test.mjs
```

生成器逐段扫描 `loadLibrary()` 验证过的整个归档，绝不读取 `catalog.subjects` 来限定检索或将整卷关联复制到所有段落。摘要由 `buildPersonPassageSummary()` 从共享关联派生，供前端构建使用。独立复核过的编年省略主语补充保存于 `chronology-subjects.json`，每项记录具体段落、人物、理由与完整原文校验值；原文不同则停止生成，不放宽全局帝号检索。

## 身份与范围

`rules.json` 保存可解释的规则和每个分节范围的首尾原文证据。稳定人物 ID 与姓名来自 `emperors.json`、`taibao.json` 、`zhu-wen-generals.json` 和 `li-keyong-generals.json` 的同一人物目录；匹配词只包含已核验原文中的姓名、异体用字、短名和称谓，不采用“康君利”“安景思”等后世演义用名。

- 本纪按实际记载主体继承。合卷的新史卷 7、10、12 分别切开前后皇帝，不因整卷 `subjects` 含两人就为两人收录全卷。
- 本传按人物小节切开。新史卷 36 第 23 段为附记康君立，第 24 段开始李存进；史敬思只有史建瑭传中明确附父的一段。后嗣独立生平不继承父亲主体；嗣昭传连述后嗣的范围单列为 `record`。
- 朱温将领分传依真实首尾段限定，排除刘鄩、张归霸、袁象先、王晏球、朱汉宾、刘玘等传中的纯后嗣独立生平；李周彝为他传记录，不虚构独立专传。王／谢彦章、李／霍彦威不使用无法消歧的共同短名，庞师古不吸收颜师古的校勘提及。
- 跨传使用原文姓名和有历史叙事语境的双字短名。张知远、张承祐、前蜀王宗训、石君立、米君立等同名人物阻止同段后续短称误归；“梁王宗训”“郑王宗训”中的王是封号，保留其正确身份。`敬思` 不全球匹配史敬思，因为它也指李存孝本名安敬思。
- 可辨认的庄宗、明宗等称谓在已核验的当前归档中匹配。太祖、高祖、末帝、帝、上、晋王等则须有明确的局部语境。编年史按实际交接段落解释，避开引用中的先晋王李克用。刘邦与南汉刘岩的“汉高祖”明确排除；“武宗至济阴废帝”中的唐哀帝李柷不归于李从珂；宋太祖不因裸称“太祖”归于朱温或郭威。
- 《五代会要》的年号归属只在同段有明确日期与敕、诏、御札等发令文字时启用。年号后须是日期或明确的奏请后裁定；普通当年事件、地名“长兴”、远离日期的夹注不能触发。交接月保守排除：乾化二年六月、天福七年六月、显德六年六月、长兴四年十一月、乾祐三年十一月等；乾祐元年与显德元年正月及显德七年也不自动归人。

`biography` 表示本纪／本传主体，`record` 表示其他已辨认记载，`mention` 用于短标题、校勘提及或仅在引书题名中出现的人物。片段标题只使用既有章节名、核验的分传名与段落序号，不自动生成史事标题。

李克用专题复用既有人物并新增军将身份，不复制每人的 slice。刘训与刘鄩、安金全与李金全分开；短名屏蔽另姓同名、“李洪建及其党”“仁罕之望”“休休亭”等跨词或地名命中。安重霸仅按全名和已核本传／评议范围归属，不全局匹配多个同名人的“重霸”。王建及兼李建及、刘训兼李绍珙、张廷裕兼张庭裕；同段或他传中的真实记载使用同一共享段落。纯后嗣独立叙事不继承父传，例如史建瑭附子只关联明确父子关系的第28段，不包含第29—30段的子辈事迹。

## 校验与局限

载入工具核对归档覆盖数、完整人物目录、书籍和章节归属、稳定 ID、修订号、每段 SHA-256、整段 code point 范围与关联类型。重复 ID、重复关联、同一段落跨片段重复、跨章 span 和乱序 span 均拒绝；支持有序的多个完整段落 span。

“当前归档”表示本轮扫描覆盖完整已收录范围，不表示未归档书卷，也不声称自动规则能穷尽每个省略指代。无法安全消歧的孤立帝号、单字名、跨段代称和交接月保持未关联；后续补充须核对原文与规则，重新生成索引并通过校验。底本或修订变化时不能继续套用旧范围。
