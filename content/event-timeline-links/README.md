# 事件对读与个人年表关联

`<comparisonId>.json` 是两个阅读方向共用的关系注册表。每条链接保存稳定人物ID、既有年表事件ID、规范化事件事实的SHA-256、已核对阶段及连续原文引用。年表到对读、对读到人物的同一事件，都由这份数据派生，不另维护第二份名单。

柏乡之战当前关联10位人物的12个既有事件，共14处阶段入口。关联范围是当前归档和既有事件：朱温出兵是背景，杨师厚、王檀守援是战后，不能把他们都显示为亲临决战。王景仁战前出兵的910—911年范围以及新旧史战日、异年分歧保持不变。

`evidence` 每条注明对读的阶段、来源ID及该来源中的连续引文；`timelineParagraphId` 和 `timelineExcerpt` 必须精确匹配这个事件原有的主证或异说引用。两端引用可以来自不同史书，但要实际阅读完整原文及已发布全文译文后核对同一事件，不能仅凭同年、地名、同段或人物关键词添加链接。

注册表不保存原文、译文全文，不改底本、年表或数据库。规范化事件事实或其来源变动后，旧SHA绑定失效，须重读受影响事件后更新。新对读与新增人物内容一并维护关联，但不得为填入口制造无证据的事件；完整源段仍从现有章节接口与随站副本读取。

执行 `node --experimental-strip-types --test tests/event-timeline-links.test.mjs` 和既有前端检查。`content/event-timeline-links.mjs` 核对双向入口共用数据、稳定身份、阶段归属、真实引文、当前原文及完整译文；结构验证不能代替史事语义复核。完成后沿项目约定部署、在线验收并备份到指定私有仓库。
