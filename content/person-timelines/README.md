# 人物年表

人物年表覆盖统一目录180位人物，共2,382条事件、4,366处主证及异说引用；依据站内已归档的史料和已发布译文制作，不宣称穷尽所有史事。李克用、李存勖既有各26条重要事件保持；其余人物和未来新增人物按同一流程维护有出处的事件。原文证据继续按[归档来源与授权](../five-dynasties/README.md)保存。

每个事件使用稳定ID，保存西历排序年份、同年顺序、原书记日、原书日期粒度、阶段、摘要和证据。证据仅含章节／段落ID、原文修订、SHA-256和连续繁体引文，不复制完整正文或译文。史书分歧使用独立 `variants`，各自保存日期、可核年份和证据；传闻、实际即位、称王及追尊分别说明。引文存在不代替语义核对。

不能核准单一西历年时使用 `year:null`、`phase:uncertain`：无可核范围为 `precision:undated`；有据范围为 `precision:range` 和 `yearRange:{start,end}`。确年事件按年排列，不确年记载置后按原书叙次展示，不用年号起算、在位年数或年龄倒推来补造日期。资料稀少的人物据实保留实际记载，不能用空文档、人物名字或虚构生卒凑数。

跨年的史事不能直接以年号起算：沙苑之战列886，入幽州列895，旧史进封晋王列896、新史另列895；存勖胡柳之战列919、入洛阳列924，攻幽州913与捕获刘守光914分列。出生旧史十月列885，《五代会要》十二月另列886，不据年龄倒改底本。[台湾大学DocuSky中西历工具](https://docusky.org.tw/DocuSky/docuTools/RefLookupTools/CeJsEraDate/CeJsEraDate.html)采用CeJS；必须核对解析年号／年／月，拒绝不存在日期或超出纪年的回退。其古代日期输出用儒略历，本资料只核年份，不发布推算西历月日；原书日期及差别继续保留。

`content/person-timelines.mjs`严格核对文件名、人物、稳定事件ID、排序、来源修订／校验与连续引文。`npm run timelines:check --prefix backend`另检查完整人物目录覆盖及当前已发布全文绑定；前端prebuild和正式导入缺人物年表时停止。prebuild派生入口摘要及公开最小副本，来源读现有章节与匹配已发布译文。API一条SQL读取全部证据，任一主证或异说失效、缺当前全文译文就暂停整事件。有效空API或无效响应不由旧静态覆盖，仅网络离线时用经同规则核验的随站版本。

更新后执行共享内容、前后端及归档检查；数据库独立007索引导入经修改前备份、最终同批隔离恢复验证、全批回滚／幂等及旧表行序列保持后才正式执行。原文、旧译文与校订历史不改。只给实际有文档的人物显示入口，出处定位原段并返回原事件。主项目提交与部署、线上核对及指定私有仓库完整恢复备份后才算发布完成，私有校核报告和运行凭据不上站。

新增人物、补充史料或修订事件时执行[人物年表技能](../../.agents/skills/historical-person-timelines/SKILL.md)，同一次内容工作完成事实对读、独立复核、全目录覆盖、索引与静态副本、部署及备份；自动维护不通过后台程序猜测史事。
