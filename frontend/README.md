# 中国古代史 · 前端

React 19 + TypeScript + Vite，当前内容聚焦五代。组件使用 `.tsx`，数据和 API 模块使用 `.ts`。

当前前端暂时只开放“人物”：默认首页和全局导航进入人物页，原首页、时序、史料库、地图地址会回到人物页；检索也仅返回人物。人物文献入口汇总该人物的相关段落，包括他人传记中的记载，按文献与篇章显示完整文白对照；可定位完整章节及返回汇总页，在线校订仍使用既有受保护的完整段落流程。

人物记载索引在 `../content/person-passages/`，只保存稳定人物、章节、段落和原文版本引用，不复制正文或译文。预构建验证索引，生成小型人物文献摘要及 `public/history/person-passages.json` 静态副本。默认人物入口使用 `#person-sources/:personId/:bookId`，全部文献使用 `#person-sources/:personId`；旧完整章节路由继续可用。API不可用时读取索引与按章保存的公开副本；分页来源或可见集合变化时回到第一页，避免漏读。

白话译文默认收起，每段可以独立展开；原文每个中文句号是独立点击单位，点击后只高亮这一句，在附近显示其对应译文。引语／夹注内的句号也单独处理，不按句数或长度硬配。无法独立对应或线上校订后范围失效时，只显示说明；“查看整段译文”才会显式展开下方译文框，弹窗不扩大到整段或句组。独立 `../content/sentence-alignments/period-overrides/` 保存核对过的细范围，可在现代合译句的逗号等位置细分，绑定原文修订／校验值和译文 ID／版本／校验值。浮窗与索引按需加载，原文、译文内容保持不变。新增或重新导出的译文需运行 `node scripts/index-sentence-alignments.mjs`（项目根目录），核对范围后构建；预构建自动执行 `--check` 并逐章复制公开索引。

人物页可切换“人物名单 / 关系图”。关系图先搜索姓名或别名，再选择一个人物，只展示该人与直接相关人物的联系；初次进入和清空搜索均不绘图。关系资料区分亲属、收养／养育、部将、交恶和皇位交接，每条都有原文依据。引文支持繁简切换及具体段落阅读，手机在图内滚动查看。

新增人物从统一目录自动生成节点，关系只需核验并登记一次，两端人物的图都会自动更新。人物暂无核验关系时保留其节点并说明空状态。后续新增人物及关系时读取项目自有技能 `../.agents/skills/historical-person-relationships/SKILL.md`，不为每个人维护独立的图或坐标。

## 开发与检查

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
npm run test:sites
```

`npm run build` 先运行严格类型检查，再生成网站；GitHub Pages 的现有部署流程也会执行该检查。构建保留 Sites 所需的 `dist/client/index.html`、`dist/server/index.js` 和 `dist/.openai/hosting.json`。

`src/types.ts` 定义历史事件、人物、书籍、地点、搜索结果及章节响应类型。`src/chapter-schema.ts` 校验来自 API 的原始 JSON；格式异常或 API 不可用时，阅读页使用随站发布的完整原文副本。正文按卷加载，不进入首页主脚本。

开发和生产 API 地址分别使用 `.env.development` 与 `.env.production` 中的 `VITE_HISTORY_API_URL`。前端读取公开史料；所有者可通过受保护入口追加译文校订，校订会话仅保留在当前页面内存。网站不包含数据库密码或本机私有配置。

## 配色与侧栏

顶部“配色”按钮提供纸笺、青瓷、夜读三种页面颜色，并在本浏览器中记住选择。现有侧栏均提供收起／展开：首页史料入口、阅读目录及地图地点索引；桌面收起后主内容扩宽，手机上的阅读目录通过工具栏打开。阅读页仅保留章节目录与正文，已移除阅读辅助栏及其手机入口。侧栏状态分别保存，不影响繁简偏好。新增侧栏使用 `src/CollapsibleSidebar.tsx`，颜色使用 `src/appearance.css` 的统一色值；偏好储存失败不阻止使用。

## 繁体／简体阅读

每卷原文工具栏提供“繁体／简体”切换，默认显示归档繁体底本，选择会在本浏览器中保留（跨卷、跨书及刷新）。API 与静态归档共用同一个阅读组件；新增卷文自动支持切换。简体仅用于阅读显示，译文、署名、段落标识、修订号和底本不被修改；切回繁体直接使用底本，不从简体反向转换。

转换使用 [OpenCC JS 1.4.2](https://github.com/nk2028/opencc-js) 的通用繁转简字典，首次选择简体时才加载；字典与网站一同发布，转换不需要请求外部服务。`src/script-converter.ts` 增补已核对的五代史料年号、建筑名称，保留“乾祐／乾化／乾宁”等正确写法。新增内容应核对歧义专名，必要时增补例外及回归检查。库及字典授权为 MIT AND Apache-2.0，署名和许可随站保存在 `public/licenses/opencc-js/`。
