# 中国古代史

从史料出发，连接人物、事件与时代。网站以中国古代史为整体框架，第一期聚焦五代时期（907—960）。

在线访问：[中国古代史](https://lzww0608.github.io/)

## 当前工作版本

- 山水书卷风格首页和历史时期导航。
- 五代政权更迭年表：五个中原王朝的建立节点，支持关联人物和史料入口。
- 人物索引共 25 人，包括十四位实际在位皇帝和“十三太保相关人物”专题新增的十一人。专题复用李嗣源、李存勖既有条目，区别亲子、养子与部将；支持姓名、别名检索、在位／活动时期和政权筛选。
- 九部史料共 157 篇、7,229 段完整归档原文，均已配有公开白话译文。《旧五代史》含 59 卷皇帝本纪及卷 12、52、53、55、56 列传，共 64 篇、1,201 段；《新五代史》含卷 1—12 本纪及卷 13、25、36 列传，共 15 篇、425 段。朱友珪专传分别保留在两书家族传记中。另收《资治通鉴》五代部分及笔记、典章与考异；支持人物筛选、站内目录、原译对照和字号调整。
- 洛阳、开封、太原的地点地图与说明。
- 全站检索、移动端导航及阅读布局。

本轮“十三太保相关人物”新增六卷 185 段原文及对应译文，已完成校核、原子导入、公开发布和副本导出，当前公开译文共 7,229 条。正式数据库只读核对及备份隔离恢复检查已通过；此前 151 篇、7,044 段的原文与既有译文保持不变。静态副本需经构建、部署和在线验证后更新，部署结果以对应 GitHub Actions 流程为准。

“十三太保”是后世通俗故事中的分组，新旧《五代史》未列出共同固定十三人或排行，也不能将这些人物一概视为李克用养子。专题人物依史料记述，演义用名另作说明；河东、晋国人物归入后唐史系，条目以活动时期说明其实际年代。

界面暂时仅展示后梁、后唐、后晋、后汉、后周。当前年表展示中原五个王朝的建立节点，尚未覆盖十国及全部五代人物、事件。史料保留原页夹注与来源版本；新旧《五代史》均为选定本纪与专传，不是全书。

## 项目结构与开发

网站源代码在 `frontend/`，使用 React、TypeScript、Vite、Leaflet 和 Phosphor 图标。构建前自动执行严格类型检查，详见 [前端说明](frontend/README.md)。根目录原始的静态页面保留为早期部署记录，正式发布入口为 `frontend/index.html`。

```sh
cd frontend
npm ci
npm run dev
```

生成并预览正式版本：

```sh
npm run build
npm run preview
```

静态发布目录是 `frontend/dist/client/`。使用 hash 路由，阅读页等链接可以直接打开和刷新。原文与已发布译文从本机内容服务读取；Mac 服务离线时显示随站发布的完整原文与已发布译文副本，无需跳转外部网站。首次打开仍需能访问网站；本次未实现浏览器完全断网缓存。

## 内容后端

`backend/` 提供只读 API、PostgreSQL 数据库、原文和翻译的版本管理，以及 macOS 自动启动配置。公网使用 Tailscale Funnel 的固定 HTTPS 地址。设置、内容维护和备份说明见 [后端说明](backend/README.md)。数据库、连接密码、隧道身份及备份均不进入 Git。

## 开发 skills

项目在 `.agents/skills/` 收录了 8 个开源前后端开发技能，涵盖界面设计、React 性能、TypeScript、Node.js API、PostgreSQL 和测试。使用场景、固定来源版本与许可证说明见 [技能目录](.agents/README.md)。可运行 `python3 .agents/verify-skills.py` 检查本地文件完整性。

## 部署

GitHub Pages 的发布来源设置为 **GitHub Actions**。`.github/workflows/pages.yml` 在 `main` 分支的前端或部署配置变化时自动安装依赖、构建和发布；也可以在 Actions 页面手动运行。

部署记录：[网站发布流程](https://github.com/Lzww0608/Lzww0608.github.io/actions/workflows/pages.yml)

## 内容、图像与参考

- 原文来自维基文库贡献者整理的公版古籍，保存为本地 JSON 及原始来源响应。来源固定版本、贡献者记录、收录卷次及授权见 [本地文库说明](content/five-dynasties/README.md)；整理文本按 CC BY-SA 4.0 共享，本站阅读提示单独呈现。
- 地图使用 [OpenStreetMap](https://www.openstreetmap.org/copyright) 现代底图，页面保留署名。地点为现代城市的大致坐标，不代表五代疆域或古城精确位置。
- 山水、书封和印章均为生成插图，并非历史文物照片、古地图或书籍影印。压缩素材位于 `frontend/public/images/`，绘图原文件保存在 `frontend/design-assets/`。
