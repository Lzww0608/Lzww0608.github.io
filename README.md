# 中国古代史

从史料出发，连接人物、事件与时代。网站以中国古代史为整体框架，当前聚焦五代十国人物，十国后期记载延伸至979年。

在线访问：[中国古代史](https://lzww0608.github.io/)

## 当前工作版本

- 界面当前仅提供人物名单、个人关系图和相关史料阅读，可按五代五个中原政权和十国筛选；唐、宋等其他时期入口仍隐藏。
- 统一目录共179位人物：十四位五代在位皇帝、十国42位主序君主及福州局部争位者卓俨明、十三太保相关人物、朱温帐下将领，以及李克用与李存勖两代军将。人物跨专题复用稳定身份，支持姓名和史载异名搜索。
- 李克用将领入口合并两代共 87 人：保留原 38 人，补充 34 名新人物和 15 个已收录身份。具体条目区分李克用旧将、续事李存勖及庄宗时期归附者；加入同一专题不等于事奉同一主将，不把庄宗军职倒填为武皇任职。
- 九部史料共197篇、8,448段完整归档原文。旧史86篇、1,678段，新史33篇、1,167段；其余为《资治通鉴》五代选卷以及笔记、典章和考异。公开白话译文按原文版本配套导出，收录选卷不等于史书全本。
- 人物文献入口汇总当前归档的本传、他传、编年与补充记载，保留完整段落对照及前后文入口。个人关系图从同一注册表双向派生，只在搜索并选人后显示其直接关系。
- 阅读支持繁简切换、三种配色、可收起目录及默认收起的白话译文。点击每个原文句号单位查看已核对应译文；不能独立对齐时提示，不回退显示整段。所有者可在受保护入口追加校订版本。

本轮追加旧史卷133—136、新史卷61—70，共14卷、514段、94,412个 Unicode 原文字，完整保留十国世家、相关列传、辑佚和校勘。十国并非全部称帝，条目区分称王、实际承主和局部争位；李煜称江南国主，刘隐等追尊人物不冒充在位皇帝。原译沿用逐段逐句核对、备份隔离恢复和同一批次原子导入流程，公开副本由实际发布版本导出；此前183篇底本及既有译文、稳定段落ID和修订历史保持不变。静态副本须经构建、部署和线上验证，部署记录以对应 GitHub Actions 流程为准。

“十三太保”是后世通俗故事中的分组，新旧《五代史》没有共同固定十三人或排行；两个将领专题也不宣称包括全部下属。河东、晋国人物在五代界面归入后唐史系，条目以真实活动时期说明年代，不虚构非皇帝的在位年份。其他时期入口、年表和地图暂时隐藏。

## 项目结构与开发

网站源代码在 `frontend/`，使用 React、TypeScript、Vite、Leaflet 和 Phosphor 图标。构建前自动执行严格类型检查，详见 [前端说明](frontend/README.md)。根目录原始的静态页面保留为早期部署记录，正式发布入口为 `frontend/index.html`。

```sh
cd frontend
npm ci
npm run dev
```

生成并预览正式版本：

```sh
npm run build
npm run preview
```

静态发布目录是 `frontend/dist/client/`。使用 hash 路由，阅读页等链接可以直接打开和刷新。原文与已发布译文从本机内容服务读取；Mac 服务离线时显示随站发布的完整原文与已发布译文副本，无需跳转外部网站。首次打开仍需能访问网站；本次未实现浏览器完全断网缓存。

## 内容后端

`backend/` 提供只读 API、PostgreSQL 数据库、原文和翻译的版本管理，以及 macOS 自动启动配置。公网使用 Tailscale Funnel 的固定 HTTPS 地址。设置、内容维护和备份说明见 [后端说明](backend/README.md)。数据库备份保存到指定私有仓库 `history_backup`；连接密码、校订凭据、隧道身份和本机运行文件不进入 Git，数据库备份不进入本公开主项目。

## 开发 skills

项目在 `.agents/skills/` 收录了 8 个开源前后端开发技能，涵盖界面设计、React 性能、TypeScript、Node.js API、PostgreSQL 和测试。使用场景、固定来源版本与许可证说明见 [技能目录](.agents/README.md)。可运行 `python3 .agents/verify-skills.py` 检查本地文件完整性。

## 部署

GitHub Pages 的发布来源设置为 **GitHub Actions**。`.github/workflows/pages.yml` 在 `main` 分支的前端或部署配置变化时自动安装依赖、构建和发布；也可以在 Actions 页面手动运行。

部署记录：[网站发布流程](https://github.com/Lzww0608/Lzww0608.github.io/actions/workflows/pages.yml)

## 内容、图像与参考

- 原文来自维基文库贡献者整理的公版古籍，保存为本地 JSON 及原始来源响应。来源固定版本、贡献者记录、收录卷次及授权见 [本地文库说明](content/five-dynasties/README.md)；整理文本按 CC BY-SA 4.0 共享，本站阅读提示单独呈现。
- 地图使用 [OpenStreetMap](https://www.openstreetmap.org/copyright) 现代底图，页面保留署名。地点为现代城市的大致坐标，不代表五代疆域或古城精确位置。
- 山水、书封和印章均为生成插图，并非历史文物照片、古地图或书籍影印。压缩素材位于 `frontend/public/images/`，绘图原文件保存在 `frontend/design-assets/`。
- 设计参考：[故宫博物院](https://www.dpm.org.cn/)、[中国哲学书电子化计划](https://ctext.org/zhs)、[Chronas](https://chronas.org/)，借鉴历史内容的展示方式和信息组织，不复制其界面或素材。
