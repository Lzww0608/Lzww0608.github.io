# 古文史料阅读

项目约定：现有和后续所有古文阅读入口都提供繁体／简体切换，并记住选择。当前项目为 React + TypeScript + Vite 前端、Node HTTP 只读 API 和 PostgreSQL；新增史料沿用现有结构。

## 共用阅读功能

- 复用 [Reader](../../../frontend/src/Reader.tsx)、[阅读偏好 hook](../../../frontend/src/use-original-script.ts) 和 [显示转换模块](../../../frontend/src/original-script.ts)。API 与随站静态归档都经过同一阅读组件；不要为单本书复制一套转换或遗漏切换按钮。
- 默认显示保存的繁体底本；简体是自动转换的阅读显示。切回繁体直接读取底本，不能从简体反向转换：發／髮等文字会合并，无法无损还原。
- 保持跨卷、跨书、刷新后的选择，沿用版本化偏好键 `ancient-history:original-script:v1`。浏览器禁止储存偏好时，阅读与切换仍须可用。
- 转换字典仅在需要简体时加载，随站发布；不要引入外部在线转换服务。加载失败保留可读的繁体原文并允许重试；离开章节或切回繁体时，过期异步结果不能覆盖当前选择。
- 按实际显示设置正文语言 `zh-Hant` / `zh-Hans`。切换按钮显示当前选择，支持键盘，窄屏不遮挡字号及章节目录。

## 底本、专名与译文

- 转换只派生显示文本，不修改数据库、API 响应或归档中的原文，不改变段落 ID、顺序、修订号、出处、校验值和署名。原文中的夹注、序文和校勘说明也保留并随正文切换。
- 复用 [转换字典配置](../../../frontend/src/script-converter.ts) 的 OpenCC 繁转简方案。新增古文时核对年号、人名、地名的歧义转换；通用转换可能把“乾祐／乾化”写为“干祐／干化”。有来源依据的例外在共用短语表中维护，并补充检查，不批量猜测或改写底本。
- 已发布的现代译文及译者署名原样显示，并保留其独立语言标记。繁简切换不等于翻译，不生成缺失译文，不显示草稿或与原文修订不匹配的译文。
- 公开归档位于 `content/five-dynasties/`；`frontend/public/history/` 是自动生成副本。遵守根目录 `AGENTS.md` 和 `frontend/AGENTS.md` 的来源、授权、稳定 ID 与校验约定。

## 验证

对相关修改运行前端构建、`npm test` 与 `npm run test:sites`。使用 [现有转换测试](../../../frontend/tests/original-script.test.mjs) 检查歧义文字、夹注、原文恢复和已发布译文不变；新增史料还需执行原有归档／后端检查。浏览器验证繁简切换、跨卷／跨书／刷新保留选择，以及窄屏布局。部署沿用用户授权和项目发布流程；本 skill 不单独授权推送、发布或数据库写入。
