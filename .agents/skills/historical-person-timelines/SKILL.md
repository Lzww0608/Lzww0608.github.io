# 人物年表维护

用户要求现有全部人物都有年表，后续新增人物时自动同步完成该人的年表。自动维护指本次人物内容工作的完整流程，事件事实须实际读取史料并核对，不运行后台任务猜测历史。

## 与新增人物同时完成

人物复用 [统一目录](../../../content/person-passages.mjs) 的稳定ID；新增人物时在同一任务制作 `content/person-timelines/<personId>.json`，已有身份跨专题只维护一份。入口与事件返回ID由 [共用加载器](../../../content/person-timelines.mjs) 自动派生，不另手写人物入口清单。先读当前归档的完整主传原译，再查该人的跨传、编年及补充记载；有证据的重要任职、征战、归附、转仕、继承、变乱、结局等应串联，不能只用姓名或通用一条简介充作年表。少资料人物据实，不为数量编造生卒、称帝或战役。

补充史料或修改人物内容时，复核受影响的人物事件。保留旧稳定事件ID，不因排序变化重编号；新增事件、引用或日期异说按现有文档追加、修订，并同步派生摘要、静态副本和正式索引。新增人物若缺年表，[覆盖检查](../../../scripts/check-person-timelines.mjs)及前端prebuild必须失败，不以空文档或占位事件消除失败。

## 事件事实与日期

schemaVersion为1、scope为current-archive，事件保存稳定ID、title、summary、year、sortOrder、precision、sourceDate、phase及evidence。每条主证及异说绑定真实chapterId、paragraphId、originalRevision、完整原文SHA-256和连续繁体excerpt；原文、全文译文继续读取既有记录，不复制或按原文字位裁译文。逐事件实际对读完整上下文和对应已发布译文，核施事、真实主将、时期与事实，不把派将写成亲征、赐名写成收养或追尊写成即位。引文存在或结构齐全不代替语义复核。

确准西历年用整数year与precision year/month/day，并另留原书记年/月/日。年号末月可能跨西历年，实际核历表解析的年号、年和月；不存在日期或超出年号范围的回退不得采纳。无可核单年用year:null、phase:uncertain：无范围precision:undated；有来源支持的范围precision:range并保存yearRange:{start,end}。范围边界是西历年且start<=end，不能再强选其中一年。确年事件先按年份及同年sortOrder排列，所有不确年记载置后按原书叙次排；界面明确“年代未定”或范围，不能装成确定时间点。按本人主传中事件实际展开的叙次安排未定记载；辅助背景段、亲属传末的附带提及以及异说的首个引文位置不能机械充作该事件的排序锚。复合事件须区分主事的确准日期与后续未独年月的经历，日期说明或notes明确适用范围，不将同段全部行为染成主事的年月日。保留原有事实限定notes，新日期说明按需追加，不能用通用提示覆盖旧说明。不同史书年份、日期、亲属称谓及记事过程以variants分别列证，不拼接为唯一事实。sourceDate是整理后的日期说明，保留其文字；只有绑定底本的引文经过共用繁简显示转换。

新人物阶段使用通用phase early、service、rule、later、fall、posthumous；特定既有人物的阶段含义保持。不确年用uncertain。保留实际人审状态，工具对读不称人工审核。私有语义报告绑定最终doc SHA、实际原文及全文译文ID/版本/双SHA；修改最终稿后重读变更事件和上下文，旧批准哈希不能复用。

## 同步、验证与发布

执行 `npm run timelines:check --prefix backend`，核对统一人物目录完整覆盖、全部引用当前原文及匹配的已发布全文。前端静态入口和最小副本由prebuild派生，复用现有可收起年度目录、三配色、原文繁简、Reader具体段落及安全内部返回。原文出处继续支持默认收起的完整译文与独立句译；参见 [古文阅读技能](../historical-text-reading/SKILL.md)。任一主证或异说失效或缺全文时暂停整事件，成功API空/无效响应不被静态旧版复活，仅网络离线使用版本有效的随站副本。

正式导入先本机及指定私有仓库baseline备份，再用实际dump在独立恢复库验证同一最终批次与复核输入、全批失败回滚、重复导入、全部旧表/序列及已有人物年表保持。`npm run timelines:import --prefix backend`只写007独立索引，不改底本、旧译文/句译、片段或校订历史。范围性schema/UI/API改动补相应测试；按项目约定执行前后端、来源、句译及技能检查。完成主项目提交、部署和线上原译定位/返回核对后，按 [内容备份技能](../history-content-backup/SKILL.md)完整恢复核验并push指定私有仓库。当前授权边界以用户与AGENTS为准，不推私稿、凭据或运行目录到网站，不新增定时任务。
